# Choo Sin Wai — Academic Homepage

A lightweight, responsive academic homepage for GitHub Pages. No build step or external font dependencies.

## Update

- Edit `index.html` for biography, news, publications, experience, and education.
- Edit `style.css` for appearance and responsive layout.
- The current avatar is a typographic monogram, not a photograph. Replace the `.monogram` element with your own portrait when ready.
- Contact email is taken from the publicly available CVPR paper. No Google Scholar profile or CV is invented.

## Preview

Run `python -m http.server 8765`, then open http://localhost:8765.

## Publish

In repository Settings → Pages, choose **Deploy from a branch**, branch **main**, folder **/ (root)**.
For the current repository name, the default project URL is **https://csw33.github.io/choosinwai.github.io/**. A root user site at https://csw33.github.io/ requires the repository name `CSW33.github.io`; this project does not rename your repository.
